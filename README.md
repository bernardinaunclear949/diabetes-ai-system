## 💡 Troubleshooting common issues

If you encounter problems, check these solutions:

* Software fails to open: Ensure you have the latest updates for Windows installed. Restart your computer if the issue persists.
* Data does not save: Check that you have written permission to the folder where you installed the program. Try running the application as an administrator.
* Graphs appear blank: Verify that you entered information for at least three consecutive days. The software requires a small set of data to create a pattern.
* Slow performance: Close other browser tabs or programs while the analysis engine calculates your trends.

## 🔒 Privacy and data storage

This application stores your data locally on your computer. No information travels to a cloud server or a third-party database. You retain full control over your records at all times. If you delete the application, your data files remain in your user profile folder unless you choose to delete them manually. You can back up your records by copying the folder labeled "DiabetesData" found in your documents directory to a USB drive or a secondary hard drive.
